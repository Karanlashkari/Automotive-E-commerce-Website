Automotive E-commerce Website 🚗
A responsive, full-stack e-commerce platform for buying and selling new and used Eicher vehicles, developed during my internship at Volvo Group & Eicher Motors JV.

🔧 Tech Stack
Frontend: HTML, CSS, JavaScript, React.js, Three.js

Backend: Node.js, Express.js

Database: MongoDB

Other Tools: Git, GitHub

🌟 Features
Dynamic product listings for new and used vehicles

User-friendly UI/UX with smooth navigation

Vehicle details with 3D interaction using Three.js
